# 验证范围

## 实际服务验收

- 原机器上 qB、CloudDrive2、Jellyfin 和整理队列已运行；具体版本和并行/限速基线见 `environment-snapshot.json`。
- 上传清理要求强制刷新云端并核对文件身份、大小和 SHA1，相关保护逻辑经过专门回归。
- 云端整理有前后清单与原始文件身份验收，不将额外 NFO 误当成原视频损坏。
- Jellyfin 桌面端分别点击剧集和电影的播放按钮，确认调用 PotPlayer 与正确 X 盘文件；已观察到中文字幕和同季播放列表。
- 朋友远程入口完成 HTTPS/API/局部读取验收，没有将本机验收夸大为朋友网络全片实测。

## 仓库离线回归

`python tools/run_checks.py` 会先检查脱敏规则，再把仓库副本放到系统临时目录，使用独立子进程运行每个测试脚本。子进程禁用 socket 连接，LocalAppData 指向临时空目录；不导入生产模块，不连接真实服务，不修改本机下载账本。

覆盖：

1. 云端未核验保留本地副本，只有核验后才能删除管理任务。
2. 云额度耗尽停止、重复来源去重、待确认任务预留名额与错误元数据哈希拒绝。
3. qB 填充文件 index 匹配、分块和最终云端重验。
4. 慢源退避、重试名额、重启状态和连接宽限。
5. 暂停部分数据的空间占用、完整活动任务预留和空闲保护。
6. 完整来源集合等待、补源独立清单和缺集编号保留。
7. 整理前后原始 ID/大小/SHA1 保留，新增 NFO 分开判断。
8. 跨季、绝对编号与已审阅来源的集数偏移。
9. 小数特别篇不覆盖整数集号。
10. 选择性缺集补全、字幕语言/版本映射。
11. PotPlayer URI 对路径穿越、库外文件、非视频、查询参数与命令字符的拒绝，中文/空格/与号路径的正确处理。

当前仓库包含 12 个测试脚本；有的包含多项断言。离线测试通过不等于网络资源永远可用、所有第三方 API 版本兼容，或新机器已经完成安装。

2026-11-04 本次归档检查结果：12/12 测试脚本通过，核心 Python 源码语法解析与 py_compile 通过，发布内容敏感模式扫描未发现命中。

## 发布边界

采用文件白名单构建内容，未从整个生产目录直接 `git add`。发布前扫描凭据模式、个人 Windows 路径、云账号字面量、真实 Tailnet 地址/邀请、GitHub 凭据和具体磁力链接。扫描报告只显示文件与规则，不回显命中的敏感值。

自动模式检查不能证明任意代码绝无隐私信息，因此还对核心源码做了人工审阅，并排除了原始报告、运行日志、收藏完整清单、所有凭据与媒体。源文件对照摘要见 `source-manifest.json`。
