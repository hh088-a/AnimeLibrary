# 完整工作总结

## 目标和最终选择

起点是已通过 CloudDrive2 挂载的 115 大容量网盘，电脑是主要观看设备，媒体集中放在 X 盘。项目从首批作品试运行，扩展到近五年新番与 Bangumi 日本动画 Top 100，最后形成“云端获取 + qB 补充 + 自动核验整理 + Jellyfin 浏览 + PotPlayer 播放”的组合。

“近五年”在本项目目录快照中指 2022—2026 年，主要选取 TV/WEB 条目，截止原目录生成日期；不是一个永远自动滚动、包含未来全部新番的保证。Top 100 是目录生成时按筛选条件取得的日本动画排名快照，也不会随网页排名变化悄悄替换已选目标。

## 存储和目录

- 统一媒体根目录 `X:\动漫`。
- 动画剧集、电影分库，保留统一作品身份与季集命名。
- 115 云下载和本地上传先进入待整理位置，完成后才移动到正式媒体目录。
- 原声、特典、字体和其他资料与正式正片区分；保留原始资料。
- 整理建立前后清单和操作日志，核对原始文件 ID、大小、SHA1。新增 NFO 作为元数据单独验收。

## 资源目录和下载

将 Bangumi 条目与映射数据关联，核对作品、季数、资源标题及候选文件。能确认的资源入队，身份不明、缺源、抓取失败和已覆盖分别记账。

早期 qB 在本地下载，再上传 115；随后启用会员支持的云端离线任务，将链接提交 115 服务器，影音不必先经过电脑。后续恢复和扩展 qB 作为补充路径，云端已有、qB 已处理和已整理资源按信息哈希及来源身份去重。

没有将“已经提交”“云任务完成”“文件已整理”“作品集数齐全”合并成一个完成状态。具体来源、任务哈希和完整收藏清单保存在机器本地，不进入此仓库。

## 并行和速度优化

qB 下载并行逐步调整，2026-11-05 上午进一步按用户要求提升至 500；活动种子上限 504，上传名额 4，空间保护保留。独立云队列最多 10 个进行中/待确认名额，最新任务每约 20 秒检查，约 15 分钟完整核对历史任务。

慢源规则兼顾无完整做种及有做种计数却不实际供数的情况。长期无进度或平均极慢的来源暂缓，保留已下载文件，30 分钟后有空位再试；重试留约 3 分钟连接宽限，临近完成的任务尽量收尾。

qB 当前实际全局限速为 `2,147,482,624 B/s`，约 2 GiB/s。用户提出过 3/4 GB/s，但本机接口测试出现数值溢出/解释异常，最终未宣称这些更高数值已经生效。限速是上限，实际吞吐取决于做种、线路、缓存和云盘，100 个并行不等于每个任务都能高速下载。

## 数据保护

本地暂存预算 160 GiB、空闲空间保护 30 GiB，分批选择文件，默认分块目标约 5 GiB。慢源已占部分空间仍计入预算，不能因暂停就忽略占用。

本地删除只发生在云端重新刷新查询并核验成功之后。先核对云端文件身份、云文件属性、大小及 SHA1，再清理脚本管理的本地任务。CloudDrive 挂载中能看到文件、上传任务队列为空，均不单独构成删除依据。核验令牌失效、SHA1 缺失、上传异常时保留本地文件。

115 返回额度不足后写持久停止标记；重启脚本不会自动清除该标记或擅自等待下一周期继续提交。暂停新增云下载不影响处理已完成资源。

## 修复和整理

修复包括 BitComet 填充文件造成的 qB 文件索引偏差、分块恢复和上传异常隔离；重新审阅并更换部分无做种/极慢来源，保留旧源的部分文件。

针对缺集，只补明确缺失的文件并保留原集号。字幕按同源和版本核对、语言标记与文件匹配处理；没有把裸视频视为已确认中文字幕版本。对剧场版、OVA、小数集、分割放送和绝对集数做了专门复核，详见修复文档。

持续整理与下载分开运行。每个来源集合都完成后才整理；同名不同版本、字幕语言/版本冲突及无法确认的编号暂缓，不覆盖现有文件，也不阻塞其他作品。

## 媒体库和播放

部署 Jellyfin Server 12.4.0 与 Jellyfin Media Player 1.12.0，正式库为动画剧集、动画电影。刷新时避免同一个扫描反复并发启动。

在桌面客户端接入 PlayBridge 与 JavaScript Injector 4.1.0.0，调用本机 PotPlayer 读取 X 盘视频。为 Jellyfin Media Player 的 NativeShell 外链接口和 Qt URL 解析做了适配，并限定到本机桌面设备。自定义 URI 处理器只接收动漫库内的视频路径，不执行拼接 shell 命令。

实际点击《白箱》第一集与《轻音少女 剧场版》的播放按钮，均成功调用 PotPlayer。《白箱》显示中文字幕，并自动列出同季 24 集。进度、已看状态、Jellyfin 的字幕/音轨选择暂不回传或传递给 PotPlayer。

## 异地观影和方案调整

先完成 Tailscale 登录、HTTPS Serve、朋友受限 Jellyfin 账户与访问规则，只允许分享设备的 HTTPS 媒体入口。完成 HTTPS 登录、库访问和局部内容读取验收，未将其描述成已经从朋友所在网络实测完整播放。

随后讨论不经过本机的 115 直连。现有 CloudDrive 服务令牌不是脱离本机的原生 115 登录凭据；朋友使用另一个客户端直接登录/授权属于不同方案。已写使用方案和授权边界，未把主账号密码、会话、API 凭据上传或分发，也未宣称已经实现只读限目录的跨机器原生 115 授权。

## 本机清理

按要求移除额外 Emby 安装及注册/启动残留，保留配置数据库备份；清理旧安装包、旧调试副本和可再生成文件。已完成清理的净回收量为 `1,017,623,726` 字节，约 1.02 GB，保留必要运行文件和未完成下载。

后续 PotPlayer 接入产生的临时安装包另行清理时，工具自动审批拒绝了删除，故该批临时文件保留。这与前面已经完成的清理是两件事，未将保留文件计入回收量。

## 未完成与后续复核

1. 目标目录尚未全部获取，数量和文件数不能替代逐条完整性验收。
2. 115 额度停止标记仍在；需要额度恢复并明确选择恢复提交后才处理新云任务。
3. 部分慢源、缺源、集数或字幕版本冲突仍需逐项解决。
4. PotPlayer 进度回传尚未实现。
5. Jellyfin 完整剧集列表的分页问题，现有交付材料不足以证明最终修复，需要实际界面复核。
6. 朋友所在网络实际观看与脱离本机的 115 直连均不能视为已验收完成。
