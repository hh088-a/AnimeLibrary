# 异地观影与 115 直连

## 已部署：Tailscale → 本机 Jellyfin

本机安装并登录 Tailscale，通过 HTTPS Serve 转发到 loopback Jellyfin。未启用公网 Funnel。共享设备的访问规则限定到媒体入口的 TCP 443；真实设备名、IP、域名、账号、邀请与规则备份留在本地。

创建过独立朋友观影账户，限制为动画剧集/动画电影两个库，非管理员，禁止媒体删除与下载，限制远程码率和并发会话。本机已有记录基线为 20 Mbps、2 会话。

验收包括 HTTPS 可达、登录、媒体库访问和小范围内容读取。它证明服务链路能返回内容，**不等于已经在朋友所在地实测全片播放、实际带宽或转码表现**。

此方案依赖本机在线、CloudDrive2 正常与家庭上行链路可用。本机睡眠/关机后，朋友不能继续通过此入口读取库。

## 讨论过：不经过本机，朋友直接访问 115

用户随后倾向让朋友直接从 115 读取。这与分享 Jellyfin 是不同的数据路径：需要朋友设备有独立客户端，并由账号持有人完成相应的 115 授权。

CloudDrive 的本机服务 API 令牌调用的是本机服务，不能因为有这个令牌，就认为朋友可以脱离本机直接登录 115。仓库未复制、发布或硬编码主账号的密码、Cookie、二维码登录结果或原生会话。

目前没有完成并验收“原生 115、跨机器、限制到动漫目录、只读、完全脱离本机”这一组合。因此只作为备选方案记录，不宣传为已部署功能。账号持有人应在实际客户端授权界面确认权限与访问范围。
